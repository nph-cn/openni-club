# 原生小程序页面截图

2026-11-15 在微信开发者工具独立 iPhone 12/13 模拟器中连接真实本地 API 拍摄。24 张 PNG 覆盖全部16个注册页面及登录、验证码输入、错误、校验中、首页骨架和网络错误、空订单、预约提交状态。图片只裁掉开发工具外框，保留状态栏和安全区，尺寸780×1688，没有重绘界面或借用Flutter图片。

`manifest.json`逐项记录源代码、角色、流程、状态和拍摄时间。`stateGroup`支持 ready、loading、empty、error、verification。登录及验证码属于 auth 流程。同一页面的不同状态使用独立ID。

首页官方游戏横幅、图标与服务封面实际通过HTTPS加载。客户在原生界面提交三角洲PC 60分钟预约，产生18:40的本地待派单订单，服务端金额3900分，没有扣款。成员待接订单与31.20元演示账本通过HTTP创建、派单、履约及客户确认流程产生，未直接改数据库，也未执行真实转账。

手机号使用显式开启的本地SMS测试供应商，验证码是API真实生成的测试值，没有发送短信。界面实际验证了错误码、重发冷却与正确验证码登录。加载和校验中状态通过本地代理延迟真实API响应捕获，产品代码没有人为延迟。拍摄结束已恢复默认API地址并停止临时服务。
