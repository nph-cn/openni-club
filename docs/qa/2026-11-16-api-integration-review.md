## 本轮修复

1. 持久目录重启测试先删除目录、后关闭第二个服务端，Windows 报 `EPERM`，失败钩子还会留下未退出的监听进程。两个相关测试现在先关闭所有服务及 SQLite 句柄，再删除本次临时目录；通用清理跳过已经关闭的服务。修改位于 `services/api/test/api.test.mjs` 和 `services/api/test/operations.test.mjs`。
2. 品牌生成器的链接目标测试在 Windows 创建普通符号链接时依赖额外系统权限，测试在进入断言前失败。现使用 Windows 目录联接，其他平台使用目录符号链接，继续实际验证生成器拒绝穿过链接写文件，没有跳过安全断言。修改位于 `scripts/test/branding.test.mjs`。

这两项是测试执行兼容性问题；本轮没有据此宣称修复生产业务缺陷，也未改变服务端交易规则。
