# OpenNI Club：围绕真实经营重做

2026-11-15。用户明确否定了第一版通用预约模板的品质。本文件是下一轮实现范围；未通过端到端验收的部分不能标记完成。

## 经营对象与证据

目标是已有成员、已有短视频/社群客源，希望独立经营的陪练/组队型电竞俱乐部。不是职业赛事战队管理，也不是抽取所有俱乐部佣金的多租户市场。

- [东东电竞 App Store](https://apps.apple.com/cn/app/%E4%B8%9C%E4%B8%9C%E7%94%B5%E7%AB%9E/id6505019859)：开发者将产品描述为游戏玩家社区，包含达人、动态与赛事信息。它说明品牌入口与成员内容有价值，不证明我们的俱乐部需要复制整个社区。
- [神游派单 App Store](https://apps.apple.com/cn/app/%E7%A5%9E%E6%B8%B8%E6%B4%BE%E5%8D%95/id6759830174)：开发者列出订单发布/接取、服务中换队、成员管理、收益记录、分享下单。它为履约与成员端提供产品证据，功能有效性仍是供应商自述。
- [俱乐部小助手 App Store](https://apps.apple.com/cn/app/%E4%BF%B1%E4%B9%90%E9%83%A8%E5%B0%8F%E5%8A%A9%E6%89%8B/id6499259915)：开发者列出自主抽成、报备、店铺分享与评论。
- [野羊电竞自用系统介绍](https://yeyango.com/yeyang-system/)：经营者将群报单、手工结算、权限缺失与价格混乱列为问题，强调下单/派单/结单与分成记录。这是有经营背景的单方陈述，不是独立行业统计。

以下优先级是根据上述公开资料和用户目标作出的设计判断。还没有对真实俱乐部访谈，因此不编造转化率、客单价、成员数或“验证过的增长”。Mobbin 连接在本轮连续返回内部错误，未取得可查看参考图，不将任何未查看产品列为视觉参考。

## 三种角色要完成的事

客户：明确服务边界、费用、可约时间和谁来服务；下单后知道谁接单、什么时候开始、如何联系；可确认交付、再次预约同一队友、申请售后。

成员：设定可接时段；知道指派的服务、时间、要求和预计收入；可接单/拒单；开始/提交交付记录；清楚每笔服务的分成、冻结原因、结算记录。

运营者：优先看到待派、待接超时、履约异常、争议与未结算；按游戏和档期派单；调整人员时保留原因；处理退款；按订单查分成并导出结算表，记录真实付款凭据。

## 首个完整业务闭环

客户选服务和时段 → 创建订单/付款 → 待派单 → 运营指派 → 成员接单或拒单 → 已排期 → 成员开始服务 → 成员提交交付说明 → 客户确认或提出争议 → 生成可结算账目 → 运营记录实际结算凭据。

必须涵盖：待支付取消/超时关单；接单拒绝/超时释放；同一成员时间冲突；归档服务不能新购但保留订单快照；支付通知重复；退款中冻结结算；全额退款撤销可结算收入；争议冻结；重复完成/重复结算不能重复记账。

分成与付款分离：每单冻结约定分成比例，收入账本记录 gross/club/member 金额和来源订单。只在真实业务完成且未争议时可结算。人工付款记录不等于银行/微信已转账，必须填写真实凭据。首版不做储值钱包或假“提现成功”。

## 客户与成员页面

客户：俱乐部首页、服务发现、服务详情、队友目录/详情、选择时间/预约、确认订单、订单列表、进度与交付详情、售后申请、通知、个人中心、政策/设置。

成员：工作台、待接订单、履约详情与提交记录、可接时段、收入与结算。演示可明确切换角色；生产角色必须来自服务端成员绑定，界面切换不能获得权限。

运营：今日待办、派单台、订单详情/时间线、成员与排班、收益结算、售后队列、内容管理、品牌与发布设置。首页不能用大面积营销口号挤掉待处理业务。

## 真正的白标交付

经营者提供名称与 Logo，即可生成有完整默认内容结构的可预览应用。品牌色、应用显示名、图标、所有文案来源、客服/政策和公开 AppID 由一份配置贯通三端。第三方秘密独立保管。上线检查区分：可预览、可构建、真机已测、商户已联调、可提交审核；不把“生成安装包”显示为“已上架”。

默认模板覆盖可用的俱乐部业务，经营者无需改 Dart/JavaScript。目录、成员、排班和价格日常在后台维护；配置更新不覆盖订单/用户。

## 设计验收

首页首屏要让人看懂“这是谁的俱乐部、有什么服务、谁现在可约、我的订单是否要处理”，不能只展示大号口号和一个卡片。成员展示用有授权的真实资料或清楚的虚构示例，不捏造评分与销量。

每种页面有适合任务的布局：探索用内容与人物；交易用费用明细和明确下一步；履约用时间线和状态；运营用紧凑队列和可执行动作。统一字体、色彩、间距不等于把所有页面做成同一种白卡。
