# 发布验收：以证据决定能否上线

下面每一项记录「通过 / 阻断 / 不适用」、证据和日期。未测试不能填写通过；仅有配置文件也不能证明外部服务已经成功。

## 产品和内容

- [ ] 已换成真实俱乐部名称、经营主体、客服、服务时间、费用和服务边界。
- [ ] 所有公开示例数据已明确标注或替换，素材具有使用依据。
- [ ] 所有页面可到达；空列表、错误、加载和返回行为可用。
- [ ] 字体放大、窄屏、屏幕阅读器标签和触控目标已实测。
- [ ] 截图来自当前版本的真实界面，页面目录不展示未实现能力。

## 账号与数据（当前正式运营阻断）

- [ ] 正式认证适配完成，demo 身份接口关闭，过期/撤销会话无效。
- [ ] 用户 A 不能读取/取消用户 B 的订单；管理员令牌不在客户端包中。
- [ ] 实现账号注销和必要数据删除流程。
- [ ] 明确联系方式等数据的用途、保存期限和第三方接收方。
- [ ] 在独立测试目录恢复备份成功，备份本身加密且访问受控。

## 预约与支付

- [ ] 预约时间、金额和服务 ID 在服务端校验，重复点击不重复下单。
- [ ] 排班/可预约容量与实际履约规则一致；没有库存能力时不可宣称已锁定档期。
- [ ] 若不开收款，界面明确预约待确认且不显示支付成功。
- [ ] 若开收款，已实现支付验签、重复通知幂等、查单和金额核验。
- [ ] 取消/退款规则、失败重试、对账与客服争议流程已验证。
- [ ] 支付方式适合真实业务性质和目标平台规则。

## 部署与端到端

- [ ] DNS 已 Active，证书有效，API 实际返回正确实例。
- [ ] 个人信息/登录/订单接口未缓存，CORS 仅放行必要来源。
- [ ] 生产和测试数据、密钥、商户配置相互隔离。
- [ ] iOS 真机与 Android 真机完整流程通过，网络中断可恢复。
- [ ] 小程序真机完整流程通过，合法域名与正式 AppID 校验开启。
- [ ] 更新/回滚流程可执行，记录版本号、数据库版本与构建产物。

## 平台提交

- [ ] Apple / Android 商店 / 微信主体、协议、应用信息与所需资质完成。
- [ ] 真实隐私政策、条款、客服、账号删除入口可公开访问。
- [ ] 审核账号有效，后端在审核期间可访问。
- [ ] 若允许用户生成内容，举报、屏蔽、审核与联系方式可用。
- [ ] 审核结果和实际上线状态分别留档，没有把“上传成功”写为“已上线”。
