# 第三方集成：先开通，再适配，最后联调

v0.1 的业务流程可以不依赖付费服务运行；下面是正式运营需要准备的接口清单，**不是已经全部实现的插件列表**。不要先购买一堆服务包，先确定用户真实需要的能力和平台是否允许。

| 能力 | 准备材料 | 客户端可放 | 仅服务端 | 当前状态 |
| --- | --- | --- | --- | --- |
| API | 域名、HTTPS、托管账号 | API_BASE_URL | 数据库和管理员凭证 | 演示业务已实现 |
| 微信登录 | 小程序/开放平台账号 | AppID、登录 code（短期传输） | AppSecret、服务端会话 | 小程序与原生身份交换已实现，待自有账号联调 |
| 短信登录 | 短信供应商、签名和模板审核 | 验证码输入 | AccessKey、验证码摘要和限流 | 待适配 |
| 微信支付 | 商户入驻、业务类目、AppID 绑定 | 服务端返回的合法支付参数 | 商户私钥、API v3 Key、平台证书/公钥配置 | JSAPI/APP、查单、全额退款及退款同步已实现；待真实验收，自动账单未实现 |
| 支付宝 | 商户和应用、对应产品签约 | 服务端生成的支付参数 | 应用私钥、验签公钥 | 待适配 |
| Apple / Google 应用内购买 | 按真实商品/服务性质判断 | 产品 ID | 回执校验/通知处理凭证 | 待评估及适配 |
| 消息 / 语音 | IM/RTC 项目和费用策略 | AppID、短期用户票据 | 管理密钥、票据签名密钥 | 未集成 |
| 推送 | APNs / Android 厂商账号 | 设备 token、公开标识 | APNs 私钥、厂商服务端密钥 | 未集成 |
| 图片 / 视频 | 对象存储、权限和审核策略 | 短时上传凭证、公开资源 URL | 永久读写密钥 | 未集成 |

密钥放进服务端环境后，还需要代码使用它们。当前服务器没有读取的变量不要当成有效配置。配置检查器只报告配置形状，不证明商户已审核、密钥有权限或接口可用。

已实现的微信模块、环境变量和逐步联调方法见 [微信接入教程](09-wechat-adapters.md)。本次测试使用本地生成的测试 RSA 密钥和模拟响应，没有向微信创建真实支付订单。

## 真实登录适配的验收

替换演示入口前，先在后端实现供应商身份验证，建立本项目的用户 ID 与外部身份映射，签发有过期时间的会话，并支持撤销。客户端只保存必要会话，错误不回显 AppSecret。对验证码和登录接口限流；相同外部用户不能反复创建不同内部账号。正式模式禁止 `/auth/demo`。

还应支持注销、数据删除及客服处理；服务端确认操作对象属于当前用户，不能相信客户端给的 userId。登录失败不能回退成“演示登录成功”。

## 真实支付适配的验收

订单金额始终由服务器按服务目录生成，使用整数最小货币单位。先创建业务订单，再请求供应商预支付；把业务订单号、商户号和金额关联保存。

支付成功以服务端验证过的通知或主动查单结果为准，不以客户端“支付成功”弹窗为准。通知必须核对签名、商户、订单号、金额、币种；同一通知重复到达只处理一次。实现超时关闭、退款、重复退款防护、退款失败重试与账单对账。取消预约不应被自动等同于退款成功。

使用供应商允许的测试流程验证一笔完整订单，再按其规则进行小额真实验收。仅有按钮或二维码不算支付接入完成。官方文档：[微信支付](https://pay.weixin.qq.com/)、[支付宝开放平台](https://open.alipay.com/)、[Apple 购买规则](https://developer.apple.com/app-store/review/guidelines/#payments)、[Google Play 支付政策](https://support.google.com/googleplay/android-developer/answer/9858738)。

## 服务器密钥交接

让俱乐部自己持有供应商账号和密钥。开发者只能获得完成任务需要的权限；部署时从密码管理器写入宿主机秘密配置，不放入 Git、教学截图或录屏。更换维护人员后轮换相应密钥，确认旧凭证失效，并保存不含密钥值的变更记录。
